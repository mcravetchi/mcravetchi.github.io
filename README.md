# mcravetchi.github.io

Personal website of Maximilian Cravetchi, published with GitHub Pages.

## Structure

- `index.html` — homepage
- `poetry.html` — poetry page
- `essays/` — essay webpages
- `pdfs/` — essay PDF documents
- `picturereal.jpg` — homepage image
- `sitemap.xml` — sitemap for search engines

The root-level `sidetracks-1.html` and `sidetracks-2.html` files are retained as redirects to the new essay webpage locations.
