# CRAVETCHI — website

GitHub Pages website of Maximilian Cravetchi. Upload the **contents** of this folder into the existing `mcravetchi.github.io` repository, preserving its current branch and GitHub Pages settings. The existing essay URLs and PDF filenames are unchanged.

## Site files

- `index.html` — homepage; the Sidetracks heading links to the concept map
- `sidetracks-map.html` — centered, self-contained three-dimensional codex with two selectable orders: exposition (24 concepts and 47 conceptual connections) and dependence (28 directed, source-linked proposed conditions), with source references and filtering. The separate research-question section is removed. The layout remains a compact 720px column (no external dependencies).
- `essays/sidetracks-1.html` — complete HTML edition of Part I
- `essays/sidetracks-2.html` — complete HTML edition of Part II
- `pdfs/` — the original, unchanged PDF editions
- `author.html`, `poetry.html`, `picturereal.jpg` — existing pages and image
- `sidetracks-1.html`, `sidetracks-2.html` — original root redirects
- `sitemap.xml` — now includes `sidetracks-map.html`

## Reading editions

The text is selectable/searchable HTML, **not** an embedded PDF viewer. Each essay keeps the former two-column geometry and right-hand panel width, position, and height on desktop, with a thin beige border. Small screens instead use an open, full-height reading page. Headings, contents, paragraph divisions, emphasis, block quotations, enumerations, bibliography, and all footnote references (linked to numbered notes) have been retained. The PDF copies remain available as downloads.

Reading HTML reflows across screen sizes, so line endings and PDF page breaks are not preserved exactly. The original PDFs remain authoritative for original pagination. Some obvious grammatical slips were minimally corrected in the HTML only; see `EDIT_NOTES.md`.

## Indexing

Canonical links still point to the existing `/essays/` URLs. HTML text is available to crawlers in the rendered webpage, and each essay includes dated author/article structured data. Submit the modified sitemap in Google Search Console when the site is published.

## Research structure

`CODEX_ORDERS.md` explains the distinction between order of exposition and the proposed directed dependence network. Dependencies are editorially argued and linked to passages; they are not proven logical entailments.
